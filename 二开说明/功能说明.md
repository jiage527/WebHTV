# WebHTV 功能说明

本文档说明 WebHTV 5.6.4 提供的功能，分三部分：**上游 FongMi 原有能力**、**WebHTV 长期增强功能**、**本轮二次开发新增功能**。

---

## 一、上游 FongMi 原有能力（保留未动）

WebHTV 基于 [FongMi/TV](https://github.com/FongMi/TV) 二次开发，以下都是上游原本就有的能力：

- **点播**：CSP / Spider 站源聚合搜索、详情、选集、换源播放
- **直播**：M3U / TXT 直播源，EPG 节目单，频道收藏
- **Spider 运行时**：JS（QuickJS）与 Python（Chaquopy）双运行时
- **解析**：多种解析方式与嗅探
- **投屏**：DLNA 投屏发送端，Chromecast
- **播放器内核**：ExoPlayer（Media3）与 MPV 双内核
- **本地 HTTP 服务**：局域网内提供接口、代理、文件服务
- **字幕**：内嵌与外部字幕，ASS 特效字幕渲染
- **弹幕**：弹幕加载与渲染
- **配置**：多配置切换、云配置导入

## 二、WebHTV 长期增强功能（此前已交付，本轮之前就有）

这些是 WebHTV 相对上游的主要差异能力，集中在设置页的「**增强功能**」入口（手机端与电视端各有独立设置页）：

| 功能 | 说明 |
|---|---|
| **WebHome 自定义首页** | 用 HTML/CSS/JavaScript 定制站点首页，通过 App 暴露的 Native SDK 调用搜索、播放、跨域请求、资源代理、最近观看、网盘检测、状态同步 |
| **App Native SDK** | 供 WebHome 网页调用的原生能力集合 |
| **管理页面** | App 内启动局域网浏览器管理页 `/m`，管理文件、登录态、同步目录、站点注入、接口、壳代理、搜索、推送；前台服务保活 |
| **远程托管** | 自建 Cloudflare / Deno / Vercel / Go / Rust 中转服务，绑定多台设备，支持远程搜索/推送、接口配置、主页设置、一键同步；Go/Rust 版支持 WebSocket 实时通道，不支持时回退 HTTP 轮询 |
| **一键同步** | 同一局域网设备间同步配置、站源数据、登录态、WebHome 数据、搜索记录、观看历史、收藏、应用设置，各项可单独勾选 |
| **站点注入** | 添加自定义 WebHome 或通用 CSP 站点；支持粘贴松散站点 JSON 片段自动归类；站点级扩展可填 URL/JSON 或从本地 JS/CSS/JSON 生成 |
| **WebHome 扩展** | 给真实网页注入用户脚本（本地文件 / 远程链接 / 直接代码 / 表单生成 / JSON）；支持 CSP key 正则匹配；带调试工作台（Web 预览、Console/Network/Elements） |
| **观影记录同步** | 总开关 + 本机 API 修改开关 + 远端同步源 + Webhook 上报；爬虫可通过 `/api/playback/current` 读取、`/api/playback/progress*` 写入；内置五种服务端同一 URL 承接 Webhook 与增量拉取 |
| **登录态学习** | 学习 Cookie、Token、接口 Jar 网盘登录文件等登录态路径，待确认项可在管理页查看编辑，参与一键同步 |
| **APP 代理** | 配置代理地址与域名匹配规则，可按当前站点自动建议代理域名 |
| **网盘链接检测** | 内置网盘分享链接有效性检测，WebHome 与本地 HTTP API 均可调用 |
| **站点健康排序** | 自动学习站点搜索/详情/播放成功率，搜索与换源优先用更可用站点；默认保留用户配置顺序，可在弹窗内单独开启 |
| **调试日志** | 本机与局域网日志查看入口 |
| **Nostr / TMDB 推荐首页** | 基于 Nostr 中继与 TMDB 的推荐型首页示例 |

## 三之二、2026-11-13 ~ 11-14 的新增与调整

- **超分（Anime4K）**：画质增强的两档改为挂载 Anime4K 神经网络着色器（效率档 / 质量档），
  挂链后会读回 `glsl-shaders` 核对是否真的生效；超分在跑时不再叠加内置缩放核。
  需要 `gpu` / `gpu-next` 渲染器，硬解直出用不了着色器。
- **默认解码**：「设置 → 播放设置 → 播放性能 →（MPV）」新增「默认解码」硬解 / 软解，每次起播生效。

  首页默认背景换成配套横版 / 竖版插画（旋转即时切换）、去掉冷启动开屏海报。

## 四、本轮修复的线上问题（用户实际反馈）

这三个都是用户真实反馈后定位修复的，值得单独说明：

1. **MPV 无声 / 4K 慢速源卡死**
   根因：`audio-spdif` 直通列表在无直通输出端的设备上仍非空 → mpv 报音频设备初始化失败 → 音频时钟停摆 → 默认 `video-sync=audio` 使画面冻结（但解复用器仍在拉数据，所以「速率数字还在跳」）→ 起播超时换源。
   修法：在 mpv 报音频输出初始化失败时一次性把 `audio-spdif` 置空；并把直通默认关掉。

2. **MPV 黑屏卡死（有进度无画面）—— 两台设备两个不同根因**
   - 平板：随包 mpv 的 `hwdec-software-fallback` 被上游管理后从未下发，硬解失败时直接 `force_eof` → **硬解失败=永久冻结**。
   - 手机：硬件解码器产出首帧后冻结（无输出）。
   修法：统一在硬解失败/无输出/首帧后冻结三种情形下回退软解。已真机实测确认。

3. **超分/降噪档位调不回**
   根因：`clampMode` 是钳制语义，强化档 +1 被压回。
   修法：改为取模回绕，并补 reset 入口。

## 五、使用提示

- **首次启动**：需要自行添加站点配置或导入配置，本软件不内置任何影视源。
- **播放器内核**：设置内可在 ExoPlayer 与 MPV 之间切换；画质增强、A-B 循环、在线字幕等部分功能仅在 MPV 内核下可用。
- **网络存储**：在「设置 → 网络存储」添加账号，建议先「测试连接」。
- **WebHome 首页**：需要站点支持 WebHome，或自行在站点配置中指定 `homePage`。
