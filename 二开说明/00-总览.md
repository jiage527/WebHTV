## 这个软件是什么

WebHomeTV 是基于 **[FongMi/TV](https://github.com/FongMi/TV)** / CatVod 生态**二次开发**的 Android 影音应用。

它保留 FongMi 原有的点播、直播、Spider、解析、投屏、本地 HTTP 服务等能力，并重点增强了 **WebHome 自定义首页**、**App Native SDK**、**管理页面**、**远程托管**、**WebHome 扩展**、**登录态学习/同步**、**网盘链接检测**、**站点健康排序**、**观影记录同步** 和 **Nostr/TMDB 推荐首页**。

核心目标不是替换 CSP/Spider 体系，而是**让 CSP 站点首页变成一个真正可开发的网页应用**：开发者用 HTML/CSS/JavaScript 定制首页，再通过 App 暴露的 Native 能力完成搜索、播放、跨域请求、资源代理、最近观看、网盘检测和状态同步。

## 构建要求（要自己编译请看这里）

- **JDK 21**（必须；`sourceCompatibility` / `targetCompatibility` 均为 Java 21）
- **Python 3.10**（Chaquo 运行时固定要求；只有 3.11/3.12/3.13 会失败）
- **Android SDK Platform 37** + **Build Tools 37.0.0**（`compileSdk=37`、`minSdk=24`、`targetSdk=28`）
- **NDK r29**（`29.0.14206865`）仅重建 MPV/FFmpeg 时需要；**普通打包不需要装 NDK**（仓库已带预编译二进制）
- 使用仓库自带 Gradle Wrapper：**Gradle 9.5.1** + **AGP 9.2.1**
- 需要联网访问 Maven Central、Google Maven、Gradle Plugin Portal、JitPack

快速构建：

```bash
cd 源码
printf 'sdk.dir=%s\n' "$ANDROID_HOME" > local.properties
bash gradlew :app:assembleMobileArm64_v8aRelease
```

产出的 APK 在 `app/build/outputs/apk/mobileArm64_v8a/release/`。

完整的环境准备与分步说明见 `源码/README.md` 的「构建」章节。

## 发行包说明

两个包内容同源（同一提交 `e7717ab0` 构建），仅 UI 形态不同：

| 文件名 | 适用设备 | 大小 | MD5 | 架构 |
|---|---|---|---|---|
| `WebHTV-5.6.4-手机版.apk` | 手机 / 平板（触屏） | 139,349,747 字节（约 132.9 MB） | `0cd09574d77dd3b520fb5154c71b1afb` | arm64-v8a |
| `WebHTV-5.6.4-电视版.apk` | 电视 / 盒子（遥控器） | 139,492,186 字节（约 133.0 MB） | `83aa4ff7c394bf2042ae902ae847367d` | arm64-v8a |

两者均为 **5.6.4（versionCode 564）**、**Android Debug 签名**。

> 两者体积相差约 142 KB，差异来自 **电视版多出的 Leanback 遥控器 UI 资源**（`androidx.leanback` 网格布局、焦点态样式等），以及手机版多出的生物识别相关资源。功能代码一致。

> **关于签名**：该包为 **debug 签名**。这意味着：可以正常安装使用，但不能覆盖安装在「用其他签名打包的」同包名应用之上（会提示签名冲突，需先卸载旧版）。若要让用户能直接覆盖升级已发布的正式版，需配置 release 签名后重新打包（签名配置见 `源码/.github/workflows/android-release.yml`，通过仓库 Secrets 注入）。

> **数据提示**：本次发行包把数据库版本从 **37 升到 38**（新增 History 索引）。从 5.6.4 以前任意版本覆盖安装时，App 会自动执行数据库迁移，**历史记录、收藏、配置均会保留**。该迁移已用真实数据做过确定性验证。
